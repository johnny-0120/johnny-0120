## 我的作品：中原機會雷達

[中原機會雷達](https://cycu-opportunity-johnny.johnny-0120.chatgpt.site/) 是我開發的校園公告與機會整理工具，整合公開資訊、初步分類、個人化收藏與期限提醒，讓學生更容易找到與自己相關的機會。

- **想解決的問題**：競賽、獎學金、交換、實習與校園活動資訊分散，容易錯過重要公告。
- **目前的做法**：整理公開公告、標題分類、篩選與搜尋，提供收藏及提醒功能。
- **使用技術**：TypeScript、React、Cloudflare D1、Google OAuth、PWA 與 Web Push。
- **專案展示**：[功能介紹、架構及虛構示範資料](projects/cycu-opportunity-radar/README.md)（完整開發程式碼目前維持 Private）。
