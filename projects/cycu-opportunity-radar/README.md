# 中原機會雷達｜CYCU Opportunity Radar

> 學生自主開發的校園資訊整理工具，**不是中原大學官方網站**。

**[使用中原機會雷達](https://cycu-opportunity-johnny.johnny-0120.chatgpt.site/)** · **[隱私權政策](https://cycu-opportunity-johnny.johnny-0120.chatgpt.site/privacy)**

## 想解決的問題

校園公告分散在 iTouch、學校首頁及不同單位網站，學生必須反覆搜尋，才有機會發現與自己相關的競賽、獎學金、交換、實習及重要期限。

中原機會雷達將公開公告整理成可搜尋、可篩選的資訊工作台，讓學生更容易發現機會、核對原始公告並安排後續行動。

## 功能

- **公開資訊彙整**：整理目前已接入的校內外官方公開來源；並非全校公告完整收錄。
- **標題分類**：根據標題、發布單位與來源做初步分類；分類結果可能有誤，請以原始公告為準。
- **個人化整理**：依關注領域篩選，保存收藏、已處理與不感興趣狀態。
- **期限與提醒**：擷取有明確依據的日期，提供倒數提醒；不確定的期限不應當作正式截止日。
- **跨裝置使用**：響應式網頁、PWA 安裝，以及使用者主動啟用的背景通知。
